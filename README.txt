ЗАГРУЗКА НА GITHUB PAGES
Загрузите в репозиторий все 5 файлов: index.html (вход), student.html (сайт ученика),
teacher.html (сайт учителя), lesson.json (текст урока), users.json (логины и пароли).
Settings -> Pages -> ветка main, папка /(root).
Ссылка для всех одна: https://anvarmakulov524-afk.github.io/РЕПОЗИТОРИЙ/
Ученик и учитель вводят логин и пароль, и каждого перекидывает на свой сайт.

АККАУНТЫ: войдите как учитель, блок "Аккаунты учеников": добавьте ученика (ФИО, логин, пароль),
скачайте users.json и загрузите в GitHub вместо старого. Пароли после добавления видны только
на экране, запишите их. Новый пароль учителя можно задать там же.

УРОК: в кабинете учителя блок "Редактор урока" -> "Скачать lesson.json" -> загрузить в GitHub.
НОМЕР WHATSAPP: в student.html строка TEACHER_PHONE="" -> номер без плюса.
